# Lumiflavin-vibrational-PESs
Supporting Information for "Following Flavin’s Vibrational Modes to Probe Anharmonicities and Low-lying Conical Intersections."

Folder PESs_0.01 contains sample input files, output files, and energies for potential energy scans along each lumiflavin (LF) vibrational normal mode.

Folder freq_coord contains all the normal modes computed for LF's ground state.

opt_coord.txt is the optimized geometry for LF in the gas phase.
